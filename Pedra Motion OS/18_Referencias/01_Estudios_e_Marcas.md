# Estúdios e Marcas — Princípios Extraídos

> **Objetivo:** o "porquê funciona" de cada referência estética. Aplicar os **princípios**, não copiar peças.

| Referência | Princípios para roubar (like an artist) |
|---|---|
| **Netflix Documentary** | cold open forte; ritmo respirado; grade de cor rica; entrevistas + b-roll cinematográfico; tensão narrativa antes da resolução. |
| **Apple** | minimalismo; espaço negativo; um produto por tela; tipografia limpa; reveal com silêncio→impacto; movimento lento e premium. |
| **Tesla** | escuro e dramático; luz sobre superfícies; hype contido; foco no futuro/inovação. |
| **The B1M** | engenharia como épico; escala (aéreas); "como fizeram o impossível"; storytelling de obra com números. |
| **CNBC / Bloomberg** | dataviz limpo e animado; um dado por vez; autoridade; ritmo preciso; infográficos como protagonistas. |
| **National Geographic** | awe (deslumbre); natureza/escala; paciência no plano; humanidade; luz natural. |
| **DJI** | movimento aéreo fluido; speed ramps; revelações por câmera; energia. |
| **Porsche / Mercedes-Benz** | luxo sóbrio; detalhe macro como prova de qualidade; luz esculpindo superfície; contido, elegante. |
| **Volvo Trucks** | demonstração de robustez; confiança; "prova" visual dramática (o teste); institucional forte. |
| **Scania** | força industrial; escala de maquinário; orgulho de engenharia. |

## Como aplicar ao Grupo Pedra
- **Obra épica** → The B1M + Nat Geo + DJI (escala, aérea, "feito impossível").
- **Lançamento premium** → Apple + Tesla + Porsche (reveal, luxo sóbrio, detalhe).
- **Dados/resultados** → Bloomberg + CNBC (infográficos animados, autoridade).
- **Institucional humano** → Netflix Doc + Volvo (narrativa, confiança, prova).

## Ética de referência
Estudamos ritmo, composição, linguagem de movimento e estrutura. Nunca reproduzimos trilha, roteiro, imagens ou identidade de terceiros. Ver [[_meta/Principios_do_Sistema]].
