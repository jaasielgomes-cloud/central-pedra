# Criadores — Princípios Extraídos

> **Objetivo:** táticas de retenção e narrativa dos melhores criadores. Princípios, não cópias.

| Criador | Princípios para roubar |
|---|---|
| **The B1M** | transformar engenharia em história épica; contexto→desafio→solução→número; aéreas + narração autoral. |
| **MagnatesMedia** | storytelling de negócios com arco de 3 atos; open loops constantes; motion graphics de dados; "e foi aí que tudo mudou". |
| **MrBeast** | hook nos primeiros 3s; frontload do melhor momento; nunca deixar a atenção cair; pattern interrupts constantes; escalada de stakes. |
| **Ali Abdaal** | clareza didática; promessa clara no início; estrutura em listas; ritmo confortável; valor tangível. |
| **Alex Hormozi** | densidade de valor por segundo; frases curtas e afiadas; texto sincronizado com a fala; sem enrolação; contraste de ideias. |

## Padrões universais dos que retêm
1. **Hook agressivo** (3s) e frontload do valor.
2. **Open loops** encadeados (nunca fechar todos de uma vez).
3. **Pattern interrupts** a cada poucos segundos.
4. **Legendas dinâmicas** sincronizadas com a fala.
5. **Ritmo variável** — acelera e respira.
6. **Payoff satisfatório** que recompensa quem ficou.

## Tradução para o Grupo Pedra
- The B1M/MagnatesMedia → base para **vídeos de obra e case** (engenharia como épico).
- MrBeast/Hormozi → base para **Reels/Shorts** (retenção máxima, hook, densidade).
- Ali Abdaal → base para **conteúdo educativo** (explicar engenharia com clareza).
