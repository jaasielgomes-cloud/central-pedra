# 01 · Direção Criativa

> O módulo que define **quem é o Grupo Pedra em vídeo** — o filtro que toda decisão criativa atravessa.

A direção criativa vem antes de tudo. Storytelling, motion e cor executam uma visão; este módulo define a visão.

## O papel do Diretor Criativo (o que o Claude assume)
1. Ler o roteiro e definir a **grande ideia** (a única coisa que o espectador precisa sentir).
2. Escolher o **tom** (institucional, épico, técnico, humano).
3. Selecionar a **estrutura narrativa** ([[02_Storytelling/01_Estruturas_Narrativas]]).
4. Definir a **linguagem visual** (referência de estúdio + tokens).
5. Garantir **consistência** de marca do primeiro ao último frame.
