# ★ Workflow Mestre — Roteiro → Vídeo

> **Objetivo:** o processo oficial que qualquer operador segue para transformar um roteiro em vídeo cinematográfico. 7 etapas, ponta a ponta.

```
BRIEF → ESTRATÉGIA → LOOK → STORYBOARD → PRODUÇÃO → AUDITORIA → ENTREGA
```

## Etapa 1 — Brief (inputs)
Reúna os **7 inputs** do [[14_Prompts/01_Prompt_Engine|Prompt Engine]]: tema, objetivo, público, arquivos, duração, tom, plataforma.

## Etapa 2 — Estratégia narrativa
- Defina a **grande ideia** (1 frase). → [[01_Direcao_Criativa/01_Principios_Criativos]]
- Escolha **estrutura** + **blueprint**. → [[02_Storytelling/01_Estruturas_Narrativas]] · [[11_Blueprints/00_Index]]
- Desenhe **hook** e **loops**. → [[06_Retencao/00_Index]]

## Etapa 3 — Look & feel
- Modo (escuro/claro), paleta, tipografia, grade de cor, câmera-padrão. → [[01_Direcao_Criativa/03_Direcao_de_Arte]] · [[09_Biblioteca_Visual/00_Index]]

## Etapa 4 — Storyboard
- Preencha a tabela de beats (tempo, cena, mídia, componente, transição, som).
- Mapeie arquivos aos beats. → [[10_Biblioteca_Engenharia/01_Quando_Usar_Cada_Recurso]]
- Defina trilha + SFX + beatmatch. → [[07_Sound_Design/00_Index]]

## Etapa 5 — Produção (Remotion)
- Gere o **Prompt de Produção**. → [[14_Prompts/02_Template_de_Prompt]]
- O Claude cria o projeto (estrutura + composição + componentes). → [[13_Templates/00_Index]] · [[12_Componentes_Remotion/00_Index]]
- Preview e ajuste de timing/ritmo. → [[03_Motion_Design/03_Timing_e_Ritmo]]

## Etapa 6 — Auditoria
- Rode a [[17_Auditoria/01_Rubrica_de_Auditoria|auditoria]] (Prompt de Auditoria).
- Passe os [[16_Checklists/00_Index|checklists]].
- Nota ≥ 8.0? Segue. Senão, refine (Etapa 4–5).

## Etapa 7 — Entrega
- Render multi-formato. → [[15_Exportacao/03_Render_e_Entrega]]
- Cheque zonas seguras no app real. → [[15_Exportacao/02_Zonas_Seguras]]
- Gere capa, arquive, publique.
