# Workflow de Auditoria e Refino

> **Objetivo:** ciclo de melhoria contínua para elevar a nota de um vídeo até o padrão de entrega.

## O ciclo
```
Auditar → Priorizar → Refinar → Reauditar → (repetir até ≥8.0)
```

1. **Auditar** com o [[14_Prompts/03_Prompt_de_Auditoria|Prompt de Auditoria]] → relatório com notas.
2. **Priorizar** os 3 critérios de menor nota (Hook e Retenção primeiro — peso 2).
3. **Refinar** com o módulo específico:
   - Hook baixo → [[06_Retencao/01_Hooks_e_Aberturas]]
   - Retenção baixa → [[06_Retencao/03_Pattern_Interrupts_e_Curiosidade]] + [[06_Retencao/04_Curva_de_Retencao]]
   - Motion baixo → [[03_Motion_Design/00_Index]]
   - Áudio baixo → [[07_Sound_Design/00_Index]]
   - Branding baixo → [[09_Biblioteca_Visual/00_Index]]
4. **Reauditar** — a nota subiu? Se sim e ≥ 8.0, entregar.

## Pós-publicação (loop de aprendizado)
- Após 24–48h, leia a **curva de retenção** ([[06_Retencao/04_Curva_de_Retencao]]).
- Ligue quedas a causas e registre o aprendizado.
- Alimente o próximo vídeo com o que funcionou.

## Registro
Guarde cada relatório de auditoria e a curva real. Com o tempo, o Grupo Pedra terá um banco de padrões do que retém no seu público específico.
