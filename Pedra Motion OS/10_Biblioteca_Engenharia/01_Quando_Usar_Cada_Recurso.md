# Quando Usar Cada Recurso (Engenharia)

> **Objetivo:** guia de decisão para cada tipo de material técnico. O que usar, para quê, e como potencializar em motion.

| Recurso | Comunica | Quando usar | Como potencializar |
|---|---|---|---|
| **Drone / aérea** | escala, contexto, grandiosidade | abertura, revelar o empreendimento no entorno, magnitude | push-in/pull-out lento, golden hour, música em swell |
| **Timelapse** | evolução, esforço, tempo | mostrar a obra "crescendo", progresso | acelerar + rótulo de data/semana + SFX de construção |
| **Before / After** | transformação, resultado | comparar estado inicial e final | slider/mask de transição, mesmo enquadramento, número da magnitude |
| **Planta baixa** | organização, funcionalidade | explicar layout, fluxo, metragem | animar "desenhando" as linhas, destacar áreas por vez |
| **CAD / BIM** | precisão, engenharia, técnica | detalhar sistema estrutural, instalações | revelar por camadas, wireframe→sólido, rotação orbital |
| **Render 3D** | futuro, sonho, acabamento | vender o pronto antes de existir | Ken Burns, orbit, luz de golden hour, parallax |
| **Mapas** | localização, valorização, entorno | mostrar vizinhança, acessos, potencial | pins animados, rotas desenhando, zoom de contexto→ponto |
| **Cronograma** | planejamento, confiança | comunicar fases e prazos | timeline animada, marcos entrando em stagger |
| **Indicadores / KPIs** | resultado, prova | números de entregas, m², prazo, valorização | contadores animados, ver [[10_Biblioteca_Engenharia/03_Infograficos_Tecnicos]] |
| **Comparativos** | vantagem, decisão | Pedra vs mercado, opção A vs B | barras/colunas animadas, destaque no vencedor |
| **Evolução de obra (fotos por fase)** | progresso real | storytelling de execução | crossfade no mesmo ângulo, rótulo de fase |
| **Imagens aéreas (foto)** | contexto premium | estabelecer, encerrar | Ken Burns + grade de cor |
| **Cortes técnicos** | como é feito, detalhe | explicar estrutura/camadas | animar o corte revelando camadas |
| **Detalhes construtivos** | qualidade, acabamento, prova | close em junta, armadura, material | macro + iluminação + SFX de precisão |
| **Gráficos** | dados, tendência | valorização, absorção, velocidade de vendas | linha desenhando, ponto-chave destacado |

## Sequência típica de um vídeo de obra
```
Aérea (contexto) → detalhe/close (prova) → timelapse (esforço) →
render (futuro) → dados/KPIs (resultado) → aérea final (grandiosidade) → CTA
```

## Regra de ouro
**Nunca mostre um material técnico "cru".** Todo drone/CAD/render recebe: grade de cor, movimento (mesmo sutil), rótulo tipográfico do sistema e SFX. É isso que separa "foto da obra" de "cinema de engenharia".
