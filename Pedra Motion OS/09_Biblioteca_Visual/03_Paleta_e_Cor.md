# Paleta e Cor

> **Objetivo:** regras de aplicação da paleta. A teoria emocional está em [[04_Cinematografia/03_Iluminacao_e_Cor]]; aqui são as regras de sistema.

## A regra 60-30-10
- **60%** cor base (`graphite` ou `limestone`).
- **30%** neutro de suporte (`concrete`).
- **10%** acento (`signal`). O acento é **escasso** — por isso guia o olho.

## Modo escuro vs claro
- **Escuro (`graphite`):** cinema, obra, épico, lançamento. Padrão do sistema.
- **Claro (`limestone`):** dados, institucional limpo, tela de números.
- Não misture os dois modos aleatoriamente na mesma peça — troque com intenção (ex.: dados em card claro sobre cena escura).

## Uso do acento (`signal`)
Reserve para **uma coisa por tela**: o dado-chave, a palavra que importa, o CTA, a linha que sublinha. Se tudo é laranja, nada é.

## Cores de dados
- `steel` (azul) = neutro/base de gráfico.
- `success` (verde) = crescimento/positivo.
- `alert` (vermelho) = queda/risco (raro).
- Ver componentes de dados em [[12_Componentes_Remotion/03_Dados_e_Infograficos]].

## Acessibilidade e contraste
- Texto sobre fundo: contraste mínimo alto (WCAG AA). No feed, prefira ainda mais contraste.
- Nunca texto `concrete` sobre `limestone` (some).
