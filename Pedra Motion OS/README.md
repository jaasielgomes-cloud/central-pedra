# 🪨 PEDRA MOTION OS

Sistema operacional de produção audiovisual do **Grupo Pedra** — um vault Obsidian que transforma qualquer roteiro em vídeo cinematográfico em **Remotion**, com identidade visual consistente e as melhores práticas de motion design, storytelling, retenção, sound design e cinematografia.

## Como usar

1. **Abra a pasta `Pedra Motion OS/` como um vault no [Obsidian](https://obsidian.md)** para navegar pelos links internos `[[ ]]`.
2. Comece por **[`00_INDEX.md`](./00_INDEX.md)** — o hub central.
3. Para produzir um vídeo, siga o **[Workflow Mestre](./19_Workflows/00_Workflow_Mestre.md)**.
4. Para gerar o prompt de produção, use o **[Prompt Engine](./14_Prompts/01_Prompt_Engine.md)**.
