# Gatilhos Cognitivos

> **Objetivo:** repertório de gatilhos psicológicos éticos para capturar e sustentar atenção. Usar a serviço da mensagem, nunca para enganar.

## Os gatilhos e como acioná-los em vídeo
| Gatilho | O que faz | Como acionar |
|---|---|---|
| **Curiosidade** | abre uma lacuna | pergunta, teaser, "espere até o fim" |
| **Novidade** | quebra o esperado | pattern interrupt visual/sonoro |
| **Prova social** | "outros confiam" | números de entregas, depoimentos |
| **Autoridade** | credibilidade | dados técnicos, engenharia, precisão |
| **Escassez/urgência** | medo de perder | "últimas unidades", contagem |
| **Reciprocidade** | valor gratuito | ensinar algo útil de graça |
| **Contraste** | destaca por comparação | before/after, antes vs depois |
| **História** | envolve empatia | personagem, jornada |
| ** Zeigarnik** | tarefas abertas grudam | loop aberto não resolvido |
| **Ancoragem** | referência de valor | mostrar tamanho/custo relativo |

## Sequenciar gatilhos
Não use um só. Um Reel forte encadeia: **curiosidade** (hook) → **autoridade** (dados) → **prova social** (números) → **escassez** (CTA).

## Ética Pedra
Nunca fabricar escassez falsa ou dado inventado. A marca é confiança. Gatilhos amplificam a verdade — não a substituem. Ver [[17_Auditoria/01_Rubrica_de_Auditoria]].
