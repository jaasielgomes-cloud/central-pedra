# Pattern Interrupts e Curiosidade

> **Objetivo:** ferramentas para **recuperar** a atenção nos pontos onde ela cai. O feed é um campo de batalha contra o scroll; o pattern interrupt é o contra-ataque.

## O que é um Pattern Interrupt
Uma quebra brusca do padrão atual (visual, sonoro ou de ritmo) que "reacorda" o cérebro. Depois de ~3–5s no mesmo padrão, a atenção começa a relaxar — o interrupt reinicia o ciclo.

## Tipos de interrupt
| Tipo | Exemplo |
|---|---|
| **Visual** | mudança de cena, cor, escala, flash, corte para gráfico |
| **Sonoro** | bass hit, whoosh, silêncio súbito, mudança de trilha |
| **Ritmo** | acelerar/desacelerar bruscamente, speed ramp |
| **Perspectiva** | mudar ângulo, de aérea para close, de real para render |
| **Formato** | de vídeo para infográfico, de foto para texto animado |
| **Direção** | mudar sentido do movimento na tela |

## Cadência recomendada
Insira uma mudança significativa a cada **2–4 segundos**. Ver [[02_Storytelling/04_Beats_e_Ritmo_Narrativo]].

## Curiosity Gap na prática
Crie a lacuna e prometa preenchê-la:
- "Tem um número aqui que muda tudo…" (aparece depois).
- "Repare no canto direito…" (dirige o olhar + cria expectativa).
- Teaser do resultado antes de mostrar o processo.

## Combinar com áudio
O interrupt mais forte é **audiovisual sincronizado**: corte + bass hit + mudança de cor no mesmo frame. Ver [[07_Sound_Design/00_Index]].

## Cuidado
Interrupt demais = caos e cansaço. Eles servem os pontos de queda, não substituem narrativa. Use o diagnóstico da [[06_Retencao/04_Curva_de_Retencao|curva de retenção]] para saber onde inserir.
