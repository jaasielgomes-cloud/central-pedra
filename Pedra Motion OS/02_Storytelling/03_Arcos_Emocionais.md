# Arcos Emocionais

> **Objetivo:** desenhar a "montanha-russa" emocional. Um vídeo plano é um vídeo esquecível. A emoção precisa subir, cair e resolver.

## A curva emocional
Trace o vídeo em um eixo de intensidade (0–10) por segundo. Vídeos que retêm têm **variação** — não uma linha reta.

```
Intensidade
 10 |            /\        /\___
  7 |     /\    /  \      /
  4 |    /  \__/    \____/
  1 |___/
     0s   hook   desenvolvimento   clímax   payoff
```

## Emoções-ferramenta e como evocá-las
| Emoção | Gatilho visual/sonoro |
|---|---|
| Curiosidade | open loop + close-up sem contexto |
| Admiração (awe) | escala (aérea), câmera lenta, swell sonoro |
| Tensão | música em suspensão, corte acelerando, silêncio |
| Alívio/orgulho | resolução, luz quente, trilha resolvendo |
| Confiança | dados precisos, tipografia limpa, ritmo estável |
| Pertencimento | rostos, mãos, comunidade, VO em 1ª pessoa |

## Técnica dos contrastes
A emoção é sentida na **transição** entre estados, não no estado em si:
- Silêncio → impacto sonoro = choque.
- Escuro → luz = revelação.
- Caos/velocidade → calma/slow-mo = respiro.
- Pequeno (detalhe) → grande (escala) = grandiosidade.

Sempre construa **antes** de pagar: quanto maior o build-up, maior o payoff.

## O vale antes do pico
Antes do momento mais alto, crie uma queda (pausa, dúvida, silêncio). O clímax de uma obra é maior se antes você mostrou o desafio/quase-fracasso.
