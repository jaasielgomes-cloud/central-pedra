## Como escolher a estrutura
```
É venda/lançamento?      → PAS, AIDA, Apple Keynote
É obra/feito técnico?    → Case de Sucesso, Documentário, Before/After
É emocional/institucional? → Hero's Journey, Pixar, Golden Circle
É rápido (Reel/Short)?   → Hook-Value-Payoff, Listicle, Loop
```
