# ✅ Checklist — Áudio

- [ ] Há trilha musical adequada ao tom? ([[07_Sound_Design/02_Musica_e_Beatmatching]])
- [ ] Cortes/entradas sincronizados ao beat (beatmatch)?
- [ ] SFX pontuando momentos-chave (bass hit, whoosh, impact)?
- [ ] SFX sincronizados ao **frame** exato do visual?
- [ ] Silêncio usado antes de um payoff/reveal?
- [ ] Narração (se houver) sempre inteligível (ducking aplicado)?
- [ ] Ambiência preenchendo silêncios "mortos"?
- [ ] Loudness ~-14 LUFS, picos ≤ -1 dBTP (sem clipping)?
- [ ] Áudio 100% licenciado/royalty-free?
- [ ] Testado no autofalante do **celular**?
- [ ] Versão sem música (só VO+SFX) exportada, se a plataforma adiciona trilha?
