# ✅ Checklist — Motion e Branding

## Motion
- [ ] Nenhuma entrada instantânea sem motivo (tudo com easing)?
- [ ] Nenhuma animação **linear** (exceto loops contínuos)?
- [ ] Overlap/stagger aplicado (elementos não entram todos juntos)?
- [ ] Um ponto de foco por vez? ([[03_Motion_Design/04_Hierarquia_e_Foco]])
- [ ] Durações dentro dos padrões? ([[03_Motion_Design/03_Timing_e_Ritmo]])
- [ ] Movimento de câmera sutil mesmo em stills (sem frame "morto")?
- [ ] Sem bounce exagerado / efeito "gelatina"?

## Branding
- [ ] Cores vêm dos **tokens** (regra 60-30-10)? ([[09_Biblioteca_Visual/03_Paleta_e_Cor]])
- [ ] Acento `signal` usado com parcimônia (uma coisa por tela)?
- [ ] Tipografia do sistema (sem fontes estranhas)?
- [ ] Logo/selo em posição consistente e segura?
- [ ] Grade de cor única aplicada a todo o material?
- [ ] Nenhuma transição "de app" (cubo, coração, glitter)?
- [ ] O still de qualquer frame pareceria campanha premium? (teste dos 3s — [[01_Direcao_Criativa/01_Principios_Criativos]])
