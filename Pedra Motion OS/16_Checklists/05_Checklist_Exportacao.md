# ✅ Checklist — Exportação

- [ ] Dimensão/fps corretos para a plataforma? ([[15_Exportacao/01_Specs_por_Plataforma]])
- [ ] Duração dentro do sweet spot da plataforma?
- [ ] Conteúdo essencial dentro das zonas seguras? ([[15_Exportacao/02_Zonas_Seguras]])
- [ ] Codec/bitrate adequados (sem artefatos em movimento)?
- [ ] Áudio embutido e nivelado?
- [ ] Legendas presentes e legíveis?
- [ ] Capa/thumbnail definida (frame de scroll-stop)?
- [ ] Versões multi-formato geradas (9:16 / 1:1 / 16:9) quando necessário?
- [ ] Revisado no **app real** com a UI sobreposta?
- [ ] Projeto arquivado/versionado (`src/` + `public/`)?
