# ✅ Checklist — Retenção

- [ ] Primeiro frame para o scroll (movimento + contraste/rosto)?
- [ ] Promessa clara nos primeiros 3s?
- [ ] O melhor momento foi trazido para a frente (frontload)?
- [ ] Há pattern interrupt a cada 2–4s? ([[06_Retencao/03_Pattern_Interrupts_e_Curiosidade]])
- [ ] Ritmo varia (não andamento único)?
- [ ] Cortes/entradas sincronizados ao beat da música?
- [ ] Loops mantêm curiosidade até o fim?
- [ ] O final conecta/loopa ou entrega recompensa forte?
- [ ] Sem "rampa lenta" no início (nada de vinheta/logo antes do conteúdo)?
- [ ] Legendas presentes (85% assiste sem som)?
