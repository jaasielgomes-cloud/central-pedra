# ✅ Checklist — Storytelling

- [ ] Existe **uma** grande ideia (resumível em 1 frase)?
- [ ] A estrutura narrativa foi escolhida conscientemente? ([[02_Storytelling/01_Estruturas_Narrativas]])
- [ ] O hook comunica o assunto e a promessa em ≤ 3s?
- [ ] Há pelo menos um **open loop** aberto cedo?
- [ ] Todo loop aberto é **pago** (payoff)?
- [ ] Há um arco emocional (sobe/desce), não linha reta? ([[02_Storytelling/03_Arcos_Emocionais]])
- [ ] O clímax/payoff é claro e tem build-up?
- [ ] Cada beat entrega uma informação nova?
- [ ] O CTA é único e claro?
- [ ] A mensagem sobrevive **sem áudio** (legendas/visual)?
